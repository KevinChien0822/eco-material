Environmental Issues

環保理念與現狀

了解塑膠危害，為地球做更好的選擇

🌊

塑膠污染的嚴峻性

全球每年約有 7,800 萬噸塑膠包裝材料產出，其中約 32% 排放至環境，2,500 萬噸流入海洋。傳統塑膠需要數百年才能分解。

🌱

生物可分解材料的優勢

生物可分解材料在適當的堆肥環境下，可以完全分解回歸自然，不產生塑膠微粒，從天然植物纖維取材，實現循環經濟。

⚠️

市面標示生物可分解的區分

市面上許多所謂生物可分解產品實際上是傳統塑膠加其他物質，僅能裂解成塑膠微粒，通不過國際可堆肥認證。茂茂峰林的材料屬於真正的生物可分解/可堆肥樹脂。

🌍

循環經濟與未來

全球生物樹脂材料產能持續成長，顯示市場對環保材料的需求日益增加。選擇生物可分解材料，是為下一代留下更美好環境的承諾。

真正的生物可分解 vs 虛假標示

市面許多標示「生物可分解」的產品其實無法真正分解

✕ 虛假生物可分解

  • ✕ 傳統塑膠 + 光敏促進劑 → 裂解成碎片
  • ✕ 傳統塑膠 + 玉米澱粉/碳酸鈣 → 裂解成微粒
  • ✕ 傳統塑膠 + 氧化添加劑 → 裂解成粉末
  • ✕ 無法通過國際可堆肥認證
  • ✕ 仍會產生塑膠微粒污染環境
  • ✕ 歐盟已禁用氧化降解塑膠

✓ 真正生物可分解

  • ✓ 100% 植物纖維複合材料製成
  • ✓ 通過國際可堆肥認證標準（EN 13432）
  • ✓ 完全分解回歸自然
  • ✓ 不產生塑膠微粒
  • ✓ 通過 SGS / Intertek 檢驗
  • ✓ Beta 生物基含量檢測驗證
